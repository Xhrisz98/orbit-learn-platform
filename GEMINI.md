# SkillProof Enterprise - Project Guidelines

## Professional UI & Iconography Standards
- **Zero-Emoji Policy**: No emojis are permitted anywhere in the user interface, alerts, text, code, or documentation.
- **Vector Icons Only**: All iconography must use `lucide-react` components.
- **Candidate Cards**: Never use photos or cartoon avatars. Distinguish gender professionally using vector `User` icons, stylized initials avatars, and corporate color themes (Blue for Male, Purple/Indigo for Female) with explicit bilingual text badges ("Hombre" / "Mujer" or "Male" / "Female").
- **Question Banks**: Standardized around professional industry categories and official job classifications (e.g. County of Orange job series).
